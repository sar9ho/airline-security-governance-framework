## SkyShield Airlines – Airline Security Governance Framework

This repository is a self-directed GRC and cyber risk lab simulating an airline security program. It includes:

- Asset inventory and data classification aligned with NIST CSF ID.AM
- Formal risk assessment methodology (FAIR-lite) and threat/vulnerability model
- Cyber risk register with inherent and residual risk scoring
- Multi-format risk visualizations (Excel, Power BI, Python, Mermaid)
- ISO/NIST-style policies (access control, logging, vulnerability management, etc.)
- Control catalog mapped to NIST CSF and ISO 27001 with evidence references
- Vendor risk and exception registers (policy exceptions, compensating controls)
- A small "compliance as code" script that inspects control definitions and evidence coverage
