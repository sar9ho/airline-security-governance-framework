# SkyShield Airlines – Security Governance Framework

This site documents a simulated cybersecurity governance, risk, and compliance (GRC) program for a fictional airline, **SkyShield Airlines**. It focuses on:

- Asset inventory & data classification
- Risk assessment (FAIR-lite) and threat modeling
- Policy authoring and control design
- Vendor and exception management
- Dashboards and heatmaps

Use the navigation to explore assets, risks, policies, and dashboards.
