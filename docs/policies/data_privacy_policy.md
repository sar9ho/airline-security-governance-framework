# Data Privacy Policy
**Version:** 1.0  
**Owner:** Data Protection Officer  
**Alignment:** GDPR, CCPA, NIST CSF PR.DS  

## 1. Purpose
To protect SkyShield personal data and ensure lawful, fair, and transparent processing.

## 2. Principles
SkyShield adheres to:

| Principle | Requirement |
|-----------|-------------|
| Minimization | Only collect necessary data |
| Purpose Limitation | Use only for stated business need |
| Retention Controls | Delete when no longer needed |
| Integrity & Confidentiality | Encryption + access control |

## 3. Data Subject Rights
Where applicable, individuals may request:
- Access, correction, deletion, objection, data portability

Requests: **Acknowledgement within 72 hours, completion within 30 days**

## 4. Retention Examples

| Data Type | Retention |
|------------|-----------|
| Booking data | 7 years |
| Employee HR | Employment + 5 years |
| Security logs | 12–24 months |
